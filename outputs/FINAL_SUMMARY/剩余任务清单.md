**功能需求**:

2. 支持三种finetuning模式:
   - Full: 无冻结，全部可训练
   - Partial: 冻结前2层encoder
   - Frozen: 冻结整个encoder，只训练head
3. 加载新数据集(CAWW35/LSWW35)
4. 保存finetuned模型

**技术实现要点**:
```python
# 层冻结逻辑
def freeze_layers(model, mode, num_layers):
    if mode == 'full':
        # 全部可训练
        pass
    elif mode == 'partial':
        # 冻结前2层
        for i in range(min(2, num_layers)):
            freeze_layer(model.encoder.layers[i])
    elif mode == 'frozen':
        # 冻结整个encoder
        freeze_all(model.encoder)
        unfreeze(model.head)
```
